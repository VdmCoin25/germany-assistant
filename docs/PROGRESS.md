# Прогресс по этапам

## ✅ Этап A — фундамент (16.11.2026)
- Структура, конфигурация (pydantic-settings), SQLAlchemy 2 + Alembic
- Регистрация: язык → земля → город → уровень → цель → статус (необязательно)
- Главное меню, /start /help /menu /settings /privacy /export_my_data /delete_my_data
- Mini App (FastAPI + HTML): главная, профиль, справочник, удаление данных; проверка подписи initData
- Админ: /stats /block /unblock; аналитика с псевдонимным HMAC-хешем
- 24 теста, проверка живого запуска с реальным токеном (@ukraineingermany_bot)

## ⏳ Этап B — полезное ядро
- Адаптер AI-провайдера (выбор провайдера после решения о DPA/регионе ЕС)
- Экран согласия перед первой загрузкой документа
- Разбор текста / PDF / фото: OCR, перевод, отправитель, сроки, суммы, следующие шаги, черновик ответа
- Явные пометки неуверенно распознанных дат и сумм
- Защита от prompt injection: текст документа — недоверенные данные
- Удаление файлов сразу после обработки
- Переводчик: текст, фото, голосовые

## ⏳ Этап C — работа и жильё
- Проверить условия API Bundesagentur für Arbeit (Jobsuche)
- Lebenslauf, Anschreiben, сообщение работодателю, тренировка собеседования
- Жильё: термины, чек-лист, калькулятор, письмо арендодателю

## ⏳ Этап D — монетизация
- Тарифы и лимиты в БД, Telegram Stars (после проверки правил), идемпотентная обработка платежей

## ⏳ Этап E — администрирование и запуск
- Редактирование справочника из админки, рассылки с учётом согласия, статус интеграций
- Impressum и Datenschutzerklärung после юридической проверки
