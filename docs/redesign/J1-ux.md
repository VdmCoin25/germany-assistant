# J1. UX без цвета

Серые кликабельные вайрфреймы: `docs/redesign/ux/wireframes.html` (открыть в браузере, переходы по ссылкам). Скриншоты 390×844 — `docs/redesign/ux/NN-*.png`. Цвет, шрифт и форма здесь не финальные: проверяем структуру, порядок действий и тексты.

## Карта экранов

```
Главная «Ваши отправления»
├─ Работа (одна строка-маршрут со статусом)
│   ├─ Анкета: 6 шагов → Превью «так вас увидит работодатель» → Отправлено
│   ├─ Предложения (список) → Предложение → Согласие на контакт
│   └─ Моя анкета (превью + «Изменить», показ вкл/выкл)
├─ Жильё → Термины · Документы · Калькулятор · Письмо
├─ Справочник (поиск сверху) → Тема → ссылки на официальные сайты
└─ «Ожидаются: …» — тихая строка, не кликается
Настройки (SettingsButton Telegram): язык · город и земля · уведомления · что храним · удалить данные
Раздел работодателя: отдельный вход (ссылка в боте и тихая ссылка внизу «Работы»), в J1 не рисовал — сценарий не меняется.
```

Таб-бара нет: на главной три пункта, всё остальное — вглубь и назад системной кнопкой. «Данные» и язык ушли в Настройки.

## Главная по состояниям (шаги маршрута «Работа»)

| Состояние (из API) | Строка «Работа» | Статус | Нижняя кнопка |
| --- | --- | --- | --- |
| Анкеты нет | «Заполните анкету — 2 минуты, анонимно» | Посадка (жёлтый) | Заполнить анкету |
| Анкета на проверке | «Анкету проверяет администратор» | В пути, дождь | скрыта |
| Опубликована, приглашений нет | «Анкета видна работодателям» | В пути, дождь | Моя анкета |
| Есть приглашения `sent` | «2 приглашения ждут ответа» (реальное число) | Посадка | Смотреть предложения |
| Контакт передан | «Контакт передан: Muster Gastro» | Прибыло | Смотреть предложения |
| Анкету отклонили | «Анкету не опубликовали. Исправьте и отправьте ещё раз» | Посадка | Исправить анкету |

Шаги линии маршрута: Анкета → Проверка → Предложения → Согласие → Контакт передан.
Время в шапке: «Обновлено ЧЧ:ММ» — время последней загрузки данных; срока проверки нет, поэтому «ответ до …» не показываем. Станция: город из анкеты («Berlin Hbf»), до анкеты — «Deutschland».

## Сценарий «первый вход → анкета → предложение → согласие»

1. Главная (`01`): одна жёлтая строка «Посадка» и нижняя кнопка «Заполнить анкету». Под ней — одна фраза, что увидит работодатель.
2. Анкета, 6 шагов (`04–06`), один вопрос на экран, прогресс «Шаг N из 6»:
   1. Какую работу ищете (поле + частые варианты-чипы);
   2. Где (поиск города с подсказками, земля подставляется сама);
   3. Занятость (чипы) + «могу сменами»;
   4. Немецкий (чипы A0…C1);
   5. Опыт (текст);
   6. О себе (необязательно, «Пропустить»).
   «Дальше» — нижняя кнопка; неактивна с подсказкой, чего не хватает. Черновик — в CloudStorage после каждого шага.
3. Превью (`07`): карточка ровно в том виде, как её увидит работодатель, и строка «Не видно: имя, телефон, Telegram, фото». Каждый ответ можно изменить.
4. Отправлено (`08`): линия маршрута, следующий шаг текстом. Срок не обещаем.
5. Предложения (`09`): «Ждут ответа · N» сверху, отвеченные ниже. Пусто (`17`) — что значит и одна кнопка.
6. Предложение (`10`): город, график, оплата, немецкий, сообщение, предупреждение о мошенниках. Две нижние кнопки Telegram: «Не интересно» (Secondary) и «Согласиться на контакт».
7. Согласие (`11`): что получит работодатель (ссылку на Telegram, профессию и город — ровно то, что сейчас отправляет бот) и что получите вы. Подтверждение — нижней кнопкой. Предупреждение, что отменить нельзя.

## Жильё и Справочник

- Жильё (`12`): четыре строки-входа вместо вкладок. Источники и дата проверки внизу.
- Справочник (`13`): поиск сверху, темы списком, у ссылок дата проверки.

## Состояния

- Загрузка (`15`): скелетон по форме табло.
- Ошибка / офлайн (`16`): по-человечески + «Повторить» нижней кнопкой; при офлайне — плашка сверху, черновик не теряется.
- Пусто (`17`): что значит + одно действие.
- Неактивная кнопка (`05`): подпись под ней, чего не хватает.

## Решения, которые я принял сам

1. **Без таб-бара.** Главная сама и есть меню из трёх пунктов; таб-бар дублировал бы её.
2. **Шесть шагов анкеты**, а не пять: «опыт» и «о себе» разделены, потому что «о себе» необязательно и его удобно пропустить одной кнопкой.
3. **Город — обязателен, земля — по городу.** Меньше вопросов; в базе остаются оба поля.
4. **Отказ от предложения — без подтверждения**, согласие — с отдельным экраном: отказ ничего не раскрывает, согласие раскрывает контакт.
5. **Линия маршрута на узких экранах (360 px)** подписывает только текущий шаг, остальные — точками; на 390 px подписи помещаются впритык.
6. **Раздел работодателя** в J1 не перерисовывал: он для немногих и платный; перенесу в новый стек в J4 как есть, в тех же компонентах.

## Анти-слоп (раздел 7) на уровне структуры

- Нет сетки «три карточки с иконкой», нет центрирования текста, секции разной высоты по содержанию.
- Кнопки называют действие; цифры только из API (число приглашений), «2 минуты» — оценка длины анкеты из 6 коротких шагов.
- Элементы табло с данными: станция = город, время = «обновлено», статус и линия = статус анкеты и приглашений, дождь = ожидание. Номеров путей у разделов нет — номер теперь шаг маршрута.
- Тест удалением: убрал заголовок секции «Работа» над строкой «Работа» (дублировал), убрал неактивную «Нет действий» внизу (кнопка просто скрыта), убрал вкладки Жилья (заменены списком).
