# J2. Два визуальных направления

Прототип на выбранном стеке: `webapp/` (Vite 8 + React 18.3 + TypeScript + TelegramUI 2.1.13, без SDK, свой слой `src/tg.ts`). Данные — пресеты `?demo=new|review|offers`, API подключается в J4. Telegram замокан `webapp/dev/mock-telegram.js` (тема как в Telegram для iOS, тестовый `initData`), настоящий бот не используется.

Скриншоты: `docs/redesign/look/` — 66 штук: 2 направления × светлая/тёмная × uk/ru × 390 и 360 px × 4 экрана (главная без анкеты, на проверке, с приглашениями; шаг анкеты «город»), плюс слабое устройство. Сводки: `docs/redesign/sheet-a.png`, `sheet-b.png`.

Размер сборки: JS 55,5 КБ gzip, CSS 11,6 КБ gzip (лимит 200 КБ).

## Общее для обоих

**Шапка-табло — у каждого элемента свои данные:**

| Элемент | Когда | Данные |
| --- | --- | --- |
| Станция | «Berlin Hbf»; до анкеты «Deutschland» | город из анкеты |
| «Обновлено 21:01» | время последней загрузки; часов больше нет | загрузка |
| Дождь | анкета на проверке или опубликована без приглашений | статус анкеты, число приглашений |

| Лавочка | вы на своей станции | — (часть таблички «станция») |
| Линия маршрута | Анкета → Проверка → Предложения → Согласие → Контакт передан | статус анкеты и приглашений |

Туман и случайно проезжающий поезд из старой версии убраны: за ними нет данных.

**Слабое устройство и `prefers-reduced-motion`:** класс `LOW` из User-Agent Android или системная настройка → сцена рисуется одним неподвижным кадром того же состояния (дождь не идёт, поезд уже стоит). Проверено: `*__360_light_ru_lowend.png`.

**Тема Telegram:** фон, текст, ячейки, кнопки — только `--tg-theme-*`, меняются на лету (`themeChanged`). Своих цветов два: `--board` #133A7C (шапка) и `--signal` #FFD23F (нужно действие, только заливкой с тёмным текстом).

## A — «табличка»

Шапка-табло только на главной, линия маршрута — точками под строкой «Работа». Шаг анкеты — обычный экран Telegram с полоской прогресса.

Почему так:
1. Всё, кроме одной таблички, выглядит как сам Telegram — человеку в стрессе не нужно ничего осваивать.
2. Внимание на главном экране одно: табличка → строка «Работа» → нижняя кнопка. Метафора не спорит с анкетой.
3. Меньше нашего кода и CSS — проще поддерживать двоим, меньше места для слопа.

## B — «вокзал»

Шапка-табло на каждом экране раздела (на шаге анкеты — компактная «Шаг 2 из 6 · Работа»), линия маршрута крупнее: номера путей = шаги маршрута в квадратных табличках, подписи станций. Строка шапки и статусы — моноширинными цифрами, как на табло.

Почему так:
1. История видна везде: человек всегда знает, «на каком пути» его поиск работы.
2. Номер пути наконец что-то значит — это шаг, а не номер пункта меню.
3. У продукта своё лицо в списке ботов, его легко узнать по скриншоту в канале.

Цена: на 360 px подписи станций кроме текущей скрыты (не помещаются); компактная шапка на форме отнимает 88 px высоты над вопросом.

## Анти-слоп (раздел 7) — оба направления

- [x] нет градиентов-украшений, свечений, стекла и пятен (единственный градиент — световой конус фонаря, он показывает состояние);
- [x] шрифт системный, без Inter/Geist; цвета не slate/zinc, а из темы Telegram;
- [x] у секций только подложка (`section_bg` на `secondary_bg`), без теней и рамок;
- [x] скругления по ролям TelegramUI (секции, поля, кнопки), «таблеток» нет;
- [x] нет сетки «три карточки с иконкой»; текст слева; секции разной высоты;
- [x] нет hover-увеличений и fade-up;
- [x] нет эмодзи и стрелок на кнопках;
- [x] кнопки называют действие; число приглашений — из данных; «2 минуты» — оценка длины анкеты из 6 коротких шагов;
- [x] каждый элемент табло показывает данные (таблица выше).
- [ ] **Спорное:** когда нужно действие, жёлтых два — фонарь в шапке и текущий шаг маршрута. Считаю это одним сигналом (сцена повторяет состояние), но если хотите строго один — фонарь станет белым, жёлтым останется шаг.

**Тест удалением:** убраны туман, часы, случайный поезд; убран дубль статуса в подписи строки «Работа» (статус уже в метке справа); на линии в A убраны подписи всех станций, кроме текущей в строке над линией.

## Что заметил и оставил на J3–J4

- Заголовки секций TelegramUI в стиле Android синие (`accent`) — это нативный вид Telegram, не трогаю.
- Список городов в прототипе — 8 примеров; источник данных и лицензия — до J4.
- Нижние кнопки на скриншотах нарисованы моком; в Telegram их рисует сам клиент.

## Решение (17.11.2026)

Вадим: «делай, что считаешь более гармоничным». Выбрано сочетание:
- главная — шапка-табло и линия маршрута с номерами путей (из B): номер пути = шаг, это главный смысл метафоры;
- анкета и остальные экраны — обычный Telegram с полоской прогресса (из A): на форме ничего не отвлекает от вопроса;
- моноширинный шрифт не используем — табличные цифры системного шрифта дают тот же ровный ряд без второго шрифта;
- жёлтый — только статус «Посадка» и фонарь (одно состояние), текущий шаг маршрута — синим;
- приглашение, ждущее ответа, — «Посадка» (нужно ваше действие), «Прибыло» — когда контакт передан.
