# Дизайн-система Mini App

Два приложения: **v2** (`webapp/`, React + TelegramUI, в разработке, адрес `/app-v2`) и **v1** (`app/webapp/static/index.html`, живое, адрес `/`). Ниже сначала v2 — источник правды для всех новых экранов, затем v1 как есть до переключения.

## v2 — основа

**Принцип.** Всё, что не табло, — обычный Telegram: цвета, шрифт, ячейки, кнопки берутся из темы Telegram и TelegramUI. Табло — тонкий фирменный слой: шапка, линия маршрута, статусы. У каждого элемента табло есть данные пользователя.

**Цвета.** Фон, текст, ячейки, кнопки — только `--tg-theme-*` (`themeParams`), меняются на лету по `themeChanged`. Своих цветов два:

| Токен | Значение | Одна роль |
| --- | --- | --- |
| `--board` | `#133A7C` | шапка-табло (одинакова в светлой и тёмной теме) |
| `--signal` | `#FFD23F` | «нужно ваше действие»: только заливка статуса «Посадка» с тёмным текстом `--on-signal` и фонарь в шапке; один сигнал на экран |
| `--route` | `#133A7C` светлая / `#7FA6EE` тёмная | линия маршрута (`--board` на тёмном фоне 1,6:1) |
| `--quiet` | `hint` Telegram, смешанный 75 % с цветом текста | мелкий второстепенный текст (чистый `hint` в светлой теме 3,3:1) |
| `--accent-text` | акцент Telegram, 80 % с цветом текста | статус «Прибыло» (чистый акцент iOS 4,0:1) |

**Статусы.** Посадка — нужно действие (`--signal`), В пути — ждём (`--quiet`, контур), Прибыло — есть новое (`--accent-text`, контур), Ожидается — скоро (`--quiet`, не кликается). Статус всегда рядом с пояснением текстом.

**Шрифт.** Системный (`system-ui, -apple-system, Roboto`), веб-шрифтов нет. Шкала 13 / 15 / 17 / 20 / 24 / 28, межстрочный 1.4, начертания 400 и 600, табличные цифры (`.num`) там, где цифры.

**Форма.** Скругления по ролям TelegramUI: секции ≈12, поля 10, кнопки 12; номера путей на линии маршрута — квадратные таблички 4 px. Теней нет: глубина — `section_bg` на `secondary_bg`. Отступы с шагом 4, края экрана 16, между секциями 24.

**Движение.** Только смысловое, до 200 мс; нажатие кнопки — 100 мс. Сцена шапки: дождь (ожидание), поезд въезжает один раз за 1,2 с и стоит (приглашение ждёт ответа). На Android-устройствах класса `LOW` и при `prefers-reduced-motion` — один неподвижный кадр того же состояния.

**Компоненты.**
- `Board` — шапка-табло: станция (город), «Обновлено ЧЧ:ММ», сцена по состоянию маршрута.
- `Route` — линия маршрута «Анкета → Проверка → Предложения → Согласие → Контакт передан», номера путей = шаги.
- `RouteCell` — строка табло: маршрут, пояснение, статус.
- `ActionButton` — кнопка в содержимом: обычная, нажата, неактивна с причиной под ней, загрузка. Главное действие экрана — нижняя кнопка Telegram (`useBottomButton`).
- Поиск города — ARIA-combobox на `Input` + `Cell` (стрелки, Enter, Escape).

**Тексты.** `webapp/src/i18n/uk.json` и `ru.json`, ключи одинаковые (проверяет `tests/test_webapp_locales.py`), склонение чисел через `.one/.few/.many`.

## Типографика

## Отступы, скругления, рамки, тени, движение
- Горизонтальное поле экрана: 16 px. Отступы — шкала 4 / 8 / 12 / 16 / 24 / 32.
- Форма — как у вокзальных табличек: углы прямые. `--radius: 0` для кнопок, чипов, вкладок, полей, табличек, номеров пути, тоста; `--radius-tag: 2px` только у бейджей и тегов.
- Содержимое — «строки табло»: блоки стоят прямо на перроне между линиями `--rule` сверху и снизу, без подложек-карточек. Цветная полоса 3 px слева — статус (анкета, открытая вакансия, ошибка).
- Подложка цветом — только у табличек со смыслом: главное действие (`--signal`), синяя табличка доступа (`--board`), тост.
- Теней и декоративных градиентов нет (градиент неба в шапке — часть сцены).
- Движение: дождь/туман/поезд в canvas шапки (выключаются при `prefers-reduced-motion`, пауза при скрытой вкладке); тост 180 ms; остальное без анимаций.
